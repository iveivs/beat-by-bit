# Beat by Bit

Дневник занятий на барабанах для учеников: разделы и упражнения идут строками,
дни - колонками, а каждое занятие можно оценить от 1 до 5 и дополнить заметкой.

## Возможности

- готовая программа из техники, тайминга, координации и репертуара;
- собственные разделы и упражнения;
- дневные оценки, заметки и графики прогресса;
- месячный обзор и печать;
- установка на домашний экран телефона;
- синхронизация через отдельный Firebase-проект.

## Запуск

```bash
npm install
npm run dev
```

## Публикация

Исходный код хранится в ветке `main`, а GitHub Pages - в ветке `gh-pages`.

```bash
npm run deploy:pages
npm run deploy:firebase
```

Перед публикацией нужно выполнить `npm run lint` и `npm run build`.

## Firebase

Приложение подключено к отдельному проекту `beat-by-bit-iveivs`. Данные Hab-Hob
и Beat by Bit не пересекаются. Для входа должны быть включены Email/Password и
Google, а правила из `firestore.rules` опубликованы в новом проекте.
